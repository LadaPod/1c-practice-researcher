# Скилл: Поиск практики по 1С

## Когда использовать
Есть рабочая задача любого типа — проблема заказчика, тема статьи, или просто вопрос — и для неё важно не пересказать документацию, а найти, как это реально решают на практике другие специалисты.

## Чем отличается от обычного чат-ассистента
- Ищет только по заведомо проверенному кругу источников (Инфостарт, официальный форум 1С, Хабр), а не по всему интернету — в теме 1С много устаревших и просто неверных советов.
- Учитывает контекст конкретной задачи (версия/редакция, точный текст ошибки), а не отвечает на абстрактный вопрос без данных.
- Если данных не хватает — сначала уточняет, а не гадает.
- Может учитывать вставленный вручную текст ИТС (платный ресурс) как источник наравне с найденным в интернете.

## Что делать по шагам

1. **Собрать вводные, прежде чем звать субагента:** какая конфигурация/редакция 1С, точный текст ошибки или формулировка задачи, что уже пробовали. Если Нонна сама не дала этих деталей и они важны для темы — спросить у неё напрямую (это дешевле и быстрее, чем ждать уточняющих вопросов от субагента).
2. Если есть кусок текста с портала ИТС по теме — включить его в задачу для субагента отдельным блоком, явно пометив, что это текст ИТС.
3. Передать задачу субагенту **`1c-practice-researcher`** одним точным запросом (тема/проблема + версия + текст ИТС, если есть).
4. Если субагент в ответ вернул уточняющие вопросы (а не результат) — не додумывать за него: передать вопросы Нонне, дождаться ответов, вызвать субагента повторно с дополненной задачей.
5. Получив результат — оформить его под задачу: краткий вывод сверху, дальше находки со ссылками (или пометкой «из текста ИТС»), честно отметить, если практики по теме почти нет.

## Важно
- Не выдумывать факты и ссылки — ни самому, ни за субагента.
- Не отвечать вместо субагента по памяти — реальный поиск обязателен, это и есть ценность инструмента.
- Обращение — на "Вы".
